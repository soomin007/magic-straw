# 오디오

이 폴더의 음악은 사용자가 Suno(무료 플랜)로 만든 것이다(2026-10-29). Suno 무료 플랜으로 만든 곡은 비상업적 용도로만 쓸 수 있으므로,
이 게임처럼 수업 시연에만 쓰고 판매하거나 광고에 쓰지 않는다. 만들 때 쓴 프롬프트는 `docs/concept-villains.md`의 "Suno 프롬프트" 절에 있다.
