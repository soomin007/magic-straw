# AI가 멋대로 만든 UI와 텍스트 후보 목록 (2026-10-28)

수업 챌린지("AI가 멋대로 만든 UI와 텍스트를 모두 지워 보기")를 위한 점검표다.
`CLAUDE.md`의 "확정한 방향"에 적혀 있지 않은 것은 AI가 붙였을 가능성이 높다고 보고 1번 표에 모았다.
확정한 방향에 근거가 있는 것은 2번 표에 따로 두었다. 3번 표는 지워도 되는지 사용자가 판정해야 하는 것이다.
칸의 번호로 "1, 3, 5번 지워 줘"처럼 고르면 된다. 지운 번호는 아래 "지운 기록"에 적는다.
