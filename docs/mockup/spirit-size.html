정령 크기 회색 상자

정령을 작은 물방울 모양으로 바꿀 때 얼마나 작게, 어디에 둘지를 고르는 목업이다. 생김새는 Codex의 후보 그림으로 따로 고르고, 여기서는 크기와 자리만 본다. 장면의 다른 상자는 지금 게임과 같은 src/layout.js 숫자로 그렸다.

세 장면 모두 샘지기는 사람 크기 그대로다. 파란 물방울이 정령이고, 흰 테두리의 작은 점은 얼음이 출발하는 자리(장면의 274, 139px)다. 정령의 입이 이 점 바로 왼쪽에 와야 한다.

A. 손바닥만 한 정령

키 20cm, 폭 15cm(장면에서 110 x 125px, 화면 높이의 23%)이다. 샘 가장자리 돌 위에 올라앉는다. 샘지기와의 크기 차이가 가장 크다.

B. 무릎 높이의 정령

키 30cm, 폭 22cm(장면에서 160 x 188px, 화면 높이의 35%)이다. 샘물에서 몸을 내밀고, 몸 아래쪽은 돌 턱에 가려진다. 표정을 읽기에 넉넉한 크기다.

C. 지금처럼 사람 상반신 크기

비교용이다. 지금 배치의 정령 자리(머리 116 x 144px, 상반신 324 x 132px)를 물방울 모양으로만 바꾼 것이다. 샘지기와 크기가 같아서 약자의 처지가 크기로는 보이지 않는다.
